# Rework bibliografii i przypisów

1. Format przypisów bibliograficznych wymaga dalszego ujednolicenia ze stylem oksfordzkim/tradycyjnym. Pierwsze odwołanie do źródła powinno zawierać pełny opis bibliograficzny. W obecnej wersji część przypisów jest zbyt skrócona, np. przy książce Deana nie ma wydawnictwa ani stron. Podobnie artykuły naukowe mają zakres stron całego artykułu, ale przy konkretnym powołaniu lepiej wskazać konkretną stronę albo zakres stron wykorzystany w danym fragmencie.

2. Powtarzające się źródła należy uporządkować zgodnie z zasadami stosowania skrótów typu `Tamże`, `Ibidem`, `dz. cyt.` / `op. cit.`. Szczególnie widoczne jest to przy HTML, CSS i JavaScript, gdzie trzy razy powtarza się ta sama książka Deana w osobnych przypisach. Można zrobić jeden wspólny przypis dla tych terminów albo przy powtórzeniach zastosować skróty zgodne z wymaganiami.

3. Bibliografię można w kolejnym etapie podzielić na `Literatura` oraz `Strony internetowe`. Z materiału dr Kędzi wynika, że bibliografia powinna być uporządkowana według jasnego kryterium, a przykłady rozdzielają literaturę tradycyjną i źródła internetowe.
