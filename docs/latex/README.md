# Projekt LaTeX pracy inżynierskiej

Główny plik dokumentu: `main.tex`.

## Overleaf

Najprostszy sposób połączenia z kontem online:

1. Wypchnij folder `docs/latex` do GitHuba.
2. W Overleaf połącz konto z GitHubem.
3. Wybierz `New Project` -> `Import from GitHub`.
4. Wskaż repozytorium projektu.
5. Ustaw `docs/latex/main.tex` jako główny plik kompilacji.
6. Ustaw kompilator na `XeLaTeX`, aby użyć czcionki `Times New Roman` zgodnie z wymaganiami.
7. Bibliografia została przeniesiona do treści dokumentu podczas importu pracy z DOCX.

Zmiany lokalne synchronizuj przez `git add`, `git commit` i `git push`, a następnie w Overleaf wybierz `Pull from GitHub`.
